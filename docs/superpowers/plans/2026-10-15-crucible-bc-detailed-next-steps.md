## 4. B：苯甲酸甲酯及一般二面角质量

### B1：固定输入、口径和输出

- 输入：tests/fixtures/gaff2 下的原始参数化分子；jobs/gate_mvp2_20261013/ir；同轮 scans；metrics.csv；模型/扫描身份取原 manifest 与缓存记录。
- 第一检查对象：methyl_benzoate 的 0-1、1-2、2-4 三根键；之后扩展到全部 6 个有可转键的分子、共 12 根键。
- 逐项核对原子顺序、中心键、扫描四元组、模型身份、网格、收敛信息与缓存键；不因路径相似就认定是同一批扫描。
- 原结果：1-2 键拟合残差 0.604426 kJ/mol，最终剖面 RMSE 3.35511，GAFF2 为 2.69745；滞后 0.410472 kJ/mol，最大键长变化 2.88695 pm。
- 复现时沿用既有实现的单位、能量零点与数值验证规则；CSV 已舍入，不能要求超过其记录精度的逐字相等。

建议产物放新的 jobs/torsion_diagnosis_<执行日期>/：manifest、逐帧 CSV、曲线、解释报告。既有 jobs/ 与扫描文件只读；日期使用实际执行日。

### B2：用同一组构型分解差异

当前 parameterize 对每根键的 MM 扣除均使用输入 ir，最后把所有已拟合项组合起来。它没有逐键用更新后的 torsions 重算扣除。因此“其他键替换后改变了这根键的剖面”是可检验的候选原因，尚非已确定根因。

在目标键 r 的同一批缓存构型上比较：原 GAFF2、只替换 r、替换全部目标键三种 IR；逐帧输出目标键、其他 proper、improper、bond、angle、LJ、静电及 1-4 的贡献，求和应与完整求值一致。

若其他项保持一致，应检验恒等式：

\[
E_{\mathrm{all}}(x)-E_{\mathrm{only}\ r}(x)
=\sum_{s\ne r}\left[T_s^{\mathrm{fit}}(x)-T_s^{\mathrm{base}}(x)\right].
\]

只替换 r 后的形状误差应与 Fourier 拟合残差在常数平移后相符；不相符时先查四元组/符号、项替换、常数处理和求值，不能直接归因于多键耦合。

同时保留以下指标，不替换原 Gate 指标：

| 指标 | 用途 |
|---|---|
| 原有各减自身最小值 RMSE | 与历史结果连续比较 |
| 最佳常数平移 RMSE：RMS[(E−E_ref)−mean(E−E_ref)] | 区分能量零点与形状误差 |
| 能垒、极小值角度、逐点残差 | 定位误差集中区域；有滞后时检查分支 |
| 拟合残差、滞后、几何变化 | 分开记录函数表达误差、扫描分支与结构变形 |

B2 的交付是能量账与解释；如果只解释了一部分，明确剩余部分，不通过换指标宣布缺陷消失。

### B3：诊断后只选一个有限候选实验

**2026-10-17 讨论澄清：**先评估最多 3 轮顺序重拟合仍是便宜的机制实验。但如果每次只在被更新键自己的扫描上拟合，它一般不等价于“所有扫描一起”的联合最小二乘；迭代收敛也不足以证明是联合解。要称为块坐标下降，每次块更新必须使用同一组全部扫描、相同权重、相同固定项，以及一致处理的每扫描常数项；设计矩阵不满秩时也不保证系数唯一。实现与报告必须写清使用哪个目标；每轮保留全局残差与逐键指标。B1/B2 历史报告末尾的无条件等价表述以本澄清为准，原报告不改写。

以下为建议，执行前锁定选项及资源；不自动改默认 provider：

- 若主要是其他键替换导致剖面漂移：优先评估受控顺序重拟合，固定全部键顺序，最多 3 轮，每轮都输出全部 12 根键的同口径结果。达到预算即停止；未改善不继续叠加启发式。
- 若上述方案受顺序影响明显：下一独立方案可比较同一 Fourier 形式的联合线性拟合。应先分析设计矩阵秩、条件数和各扫描的常数项；不能在看到结果后临时挑正则或掩盖不可辨识性。
- 若单键复现本身异常：先修已确认的求值/替换问题，并构造反例回归；不启动迭代搜索。
- 若误差主要来自扫描分支或函数形式：报告表示范围和所需新数据；是否采用多四元组、额外耦合项或重扫，单独作设计决定。

候选不能通过更换旧指标、只展示 1-2 键、增加 GAFF2 兜底数量来取得“全部改善”的结论。工程回归与质量比较分别报告，原兜底集合仍遵守决策 0020。

## 5. C：完整参数化流程

### C1：IR 与坐标的传递合同

当前 IR JSON 不包含坐标；_load_with_ir_in 仍从 --inpcrd 取坐标；derive-bonded 从原 AMBER 输入起步且没有 IR JSON 输出。因此只加一个 --ir-in 选项不足以打通流程。

建议先扩展已有命令，不先建大型调度器：

- derive-bonded 支持经过现有拓扑/原子顺序检查的 IR 输入，输出最终 IR JSON、所用/返回坐标及报告。
- 后续命令明确使用前一步坐标，特别是 Hessian 优化几何；记录坐标单位、来源和原子顺序。IR 文件与坐标不能凭同名自动配对。
- convert / check-equivalence 可作用于最终 IR 与对应坐标，而不是重新导入原始 prmtop 后仅检查 GAFF2。
- 约定中途失败的输出状态；不能把前一步残留文件当成本次完整结果。

建议回归：给输入 IR 一个可辨认且有效的非默认参数，经过后续各命令仍保留；给不同的输入与 Hessian 几何，确认下游使用声明的那一套；交换原子顺序或传错拓扑必须明确拒绝。

### C2：先完成局部 Hessian 路线

基础 AMBER IR → 局部 Hessian bond/angle → 最终电荷 → MLP 二面角 → 最终 IR + 坐标 → 三后端。

建议局部方法默认 mseminario，与现行设计 §6.1 一致；global_fit 继续显式选择。默认值属于接口建议，不能在本文中当成已实施。

开始只支持已有 prmtop/inpcrd/SDF 的流程。任意 SDF → GAFF2 初始化与 presets 后续单列，不让输入建模问题扩大本轮 C 的范围。

### C3：记录 H_fixed 实际依赖

修改重点：bonded/global_fit.py 的输出 provenance；报告记录和 bond/angle 参数应能相互定位。拟合前固定记录：

- 实际电荷数值、charge 来源与版本；torsion/improper 项及来源。
- LJ、混合规则、1-4 缩放、排除/1-4 关系；保留在 H_fixed 中的项集合。
- Hessian 来源、单位、原子顺序、参考几何、差分步长、先验、正则与方法配置。

依赖身份建议采用逐项规范化记录/受控快照，不用 hash 判断缓存能否复用。只记录 method="nagl" 或 model 名称不足以区分不同数值参数；也不能引用会随 report 修改而变化的共享可变对象。

建议回归：仅改变电荷或 torsion 参数后，固定项依赖记录会改变；记录可 JSON 往返；修改返回 report 不会反向改写已生成 IR 的来源记录。

### C4：先定更新规则，再暴露 global_fit

| 发生的变化 | 至少受影响的拟合/验证 |
|---|---|
| 电荷、LJ、1-4 等改变 | 二面角 MM 扣除；global_fit 的 H_fixed |
| torsion/improper 改变 | global_fit 的 H_fixed；完整剖面 |
| bond/angle 改变 | 二面角 MM 扣除；完整剖面与几何/频率 |
| 参考 Hessian 或几何/原子映射改变 | 对应 bonded 拟合；相关坐标与扫描适用性检查 |

全局拟合排在 charge/torsion 后，但它改变 bond/angle 又会影响二面角残差，存在双向依赖。建议第一版采用明确的阶段与依赖状态：记录“按哪套固定项拟合”、标记过期并在声称组合完成前拒绝静默沿用；不要默认无限自动迭代。

需先决定：阶段冻结后接受何种质量残差，或采用何种有预算上限的联合/交替方案。B2/B3 提供依据；若只完成单遍研究路径，就明确报告该范围，不能宣称已同时满足 Hessian 与所有剖面目标。

global_fit 接 CLI 时还要处理现有函数允许 k=0 下界解的行为：研究函数可保留诊断结果，标准导出按既有 IR 验证规则处理；不得静默截成正值或自动换回 GAFF2。复用现有 test_lower_bound_hit 作为边界，补 CLI 错误与产物状态验证。
