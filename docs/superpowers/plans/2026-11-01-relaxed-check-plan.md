## 1. 要回答的问题

在只拟合、只评估固定参考几何的流程里（G2 现状），能否在拟合**之前**、不用参考势，
预测出拟合后经 MM 重新松弛的剖面会差多少？若能，它决定"这根键需不需要用重新松弛的剖面做拟合目标"。

## 2. 量的定义（施工前锁定，不看结果后再改）

对键 r、扫描帧 s（参考几何 x_s，参考能量 E_ref），IR ∈ {only, all}（同 B2 定义）：

- **结果 Y**（要被预测的量）：
  - e_fix(s) = E_IR(x_s) − E_ref(s)：固定几何误差（G2/B2 现有口径）。
  - e_rel(s) = min{E_IR(y) : φ_q(y) = φ_q(x_s)} − E_ref(s)：只约束扫描四元组 q，从 x_s 出发逐帧松弛
    （不做顺序扫描，避免分支问题），LBFGS fmax 0.001 eV/Å。即 OpenFF 式的重新松弛剖面。
  - Y = RMSE_bs(e_rel) − RMSE_bs(e_fix)，bs = 最佳常数平移。单位 kJ/mol。
- **预测 X**（拟合前、与 θ_r 无关）：
  - relax(s) = 现脚本的量：E_bg(x_s) − min{E_bg(y) : Φ_r(y) = Φ_r(x_s)}，Φ_r = r 上全部四元组，
    E_bg = 该 IR 去掉 r 上的 proper（only 对应 GAFF2 背景，all 对应 G2 最终 IR 的背景）。
  - 逐帧预测 e_rel_pred(s) = e_fix(s) − [relax(s) − mean(relax)]；X = RMSE_bs(e_rel_pred) − RMSE_bs(e_fix)。
- 比较的是同一个量：都是剖面形状误差（kJ/mol，最佳平移口径），参考值都是同一条 MACE 扫描 E_ref。
- **基线**：P0 = RMSE_bs(e_fix)（G2 现有指标）；P1 = 扫描最大滞后。
- X 与 Y 的已知差别：Y 的松弛里 r 上非扫描四元组可以动、受拟合扭转项支配；X 里它们被固定。两者差多少本身就是结果的一部分。

## 3. 判据（提议，需用户同意）

- **噪声水平**：B2 报告里扫描质量正常的 11 根键最大滞后 ≤ 0.41 kJ/mol，即同一参考扫描两条分支的能量差，
  剖面差异小于这个量级分辨不出。取 σ = 0.41 kJ/mol。只适用于本项目 MACE-POLAR-1-M、10° 网格、fmax 0.005 eV/Å 的扫描；
  阶段 2 用新扫描的滞后重新取。
- **逐键分类**："重新松弛有影响" ⇔ Y > σ。看 X > σ、P0 > σ、P1 > σ 各自对这个分类的符合情况（列混淆表，不算单一分数）。
- **逐帧机制**：报告 RMS(e_rel − e_rel_pred) 与 RMS(e_rel − e_fix) 之比，看 X 解释了多少重新松弛带来的变化。不设阈值，只报告。
- **停止条件**（按笔记 §6.6）：没有任何键 Y > σ（问题在这批分子里不出现）；或 X 的分类不比 P0、P1 好；
  或只在已知的苯甲酸甲酯 1-2 上成立。出现任一条就停，不把 X 当诊断指标推进。
- 阶段 1 只有 11 根可用键，即使分类全对也只是机制验证，不是统计证据（Spearman 的标准误约 1/√10 ≈ 0.32）。
