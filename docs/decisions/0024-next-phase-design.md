## 裁定

1. **不自研 GAFF2 atom typing**（§3.1）。antechamber 是外部 typer，与 xTB/ORCA
   作外部 Hessian provider 同一模式；typing-only 调用不跑 sqm，电荷归 §11
   provider 层。若实现发现 typing 必须附带电荷路径，退路 `-c bcc` 一次取得
   typing+AM1-BCC（provenance 记 am1bcc，仍可被覆盖），开工时二选一。
2. **入口几何合同**（§3.1）：入口只检查、不优化、不生成几何；缺 3D 直接报错，
   不允许静默 ETKDG。构象生成永远是显式步骤（§10.4、§6.4.5）。第一版只做
   SDF（mol2 结构入口已由决策 0023 明确拒绝，不冲突）。
3. **平衡几何联合拟合**（§6.4.4，§6.4.3-1 预留接口的落地）：\(q^0\) 进拟合
   变量 + 梯度匹配项 \(\mathbf g^\mathrm{FF}(\mathbf x_0)=\mathbf 0\)。给定
   \(q^0\)，曲率行+梯度行+先验对 \(\mathbf k\) 仍是线性 LS；非线性只在
   \(q^0\)，交替求解。**opt-in，默认不变**；\(\mu=0\) 且 \(q^0=q(\mathbf x_0)\)
   必须逐位复现现行 global_fit（回归判据）；\(q^0\) 带物理边界。
4. **多构象联合拟合与 3 同一目标**（§6.4.5），\(C=1\) 即退化，一次设计、分两步
   交付。\(q^0\) 共享；构象集 = ETKDG → 同一参考 provider 优化 → 去重 → 能量
   窗口筛选（量级 \(C\le4\)），全部进 provenance，禁止混源。留出构象的泛化
   判据制度化（吸收 B4 待办）。charge/LJ 不进多构象目标。
5. **交替协议与组合完成判据**（§6.4.6，收 §6.4.2/#14 遗留）：
   charge → derive-torsions → global-fit 为一轮，≤ N（默认 3）轮；完成 =
   轮间逐项变化 ≤ ε **且** check-staleness 带 ε 容差全绿；不收敛停在 N 并
   报告，不静默继续。依据：单键级顺序重拟合已证各顺序收敛到同一不动点。
6. **一维多起点扫描原生做**（§10.4）：扩展现有 relaxed_scan，不引新依赖。
   分支**只进诊断、不进拟合目标**；Fourier 拟合默认消费逐点最小包络（与现行
   “正反取较低者”同构）。默认扫描协议暂不变；默认起点集 {x0} 时缓存身份与
   现行一致。不设自动兜底阈值（维持用户 2026-10-17 裁定：先看分布）。
7. **TorsionDrive 仅二维耦合扫描 opt-in**（§10.5）：一维不引依赖；采用与否、
   装不装（openmm_dev 为生产环境，不装不改）是**用户显式决策**，不是施工细节。
   wavefront 只保留逐点最优，“保留分支并比较”仍由自有诊断层承担。
8. 顺序：MVP-6 入口 → MVP-7 扫描质量 → MVP-8 平衡几何 → MVP-9 多构象+交替
   （8/9 共享目标函数设计）；MVP-4/5 既有遗留不受影响。
