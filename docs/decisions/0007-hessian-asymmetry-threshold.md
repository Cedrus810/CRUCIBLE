# 决策 0007：Hessian 不对称度报错阈值取 §2.3 表的 1e-3

- MVP-1 计划内部矛盾：§2.3 锁定表写不对称度 max|H−Hᵀ|/max|H| 超过 1e-3 报错、超过 1e-6 警告（之后用 ½(H+Hᵀ) 对称化），而 T11 必测用例 4 写"不对称度 1e-4 → 报错"。设计文档与路线图均未给出该阈值。
- 决策（用户确认，2026-10-05）：以 §2.3 锁定表为准——>1e-3 报错，>1e-6 警告。测试用例相应调整为：1e-2 → 报错、1e-4 → 警告、1e-8 → 通过且 `symmetrized` 后严格对称。计划原文"1e-4 → 报错"视为笔误。
- 平移残差、驻点、虚频阈值不受影响，仍按 §2.3 表。
