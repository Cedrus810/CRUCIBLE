# 决策 0006：真实 GROMACS 比较继续使用严格文件容差

> **已被决策 0013 取代**（2026-10-05）：用户裁定精度误差不卡 Gate；mixed 版使用 fp32 容差，乙腈移出 Gate。下文保留为历史记录。

- 已安装 2026.3 普通版为 mixed precision。既有 12×4 独立审查矩阵按 `1e-4 + 1e-7*abs(E_ref)` kJ/mol 比较，40/48 通过；最大差来自乙腈近线性角。
- 当前改动不放宽容差、不忽略真实引擎失败、不把小误差自动解释为格式转换正确。
- 生产 compare 包含真实 GROMACS 8 分项和 total。构建版本、精度、命令、输入、能量文件及数值差保留在运行目录；超差使报告/Gate/CLI 失败。
- 适配器用足够大的周期盒及覆盖所有分子内对的截断，关闭势能平移、PME、色散修正；所有周期镜像在截断之外。此处仅进行气相单点比较。
- GRO 以 1e-10 nm 精度写出。适配器将构型刚性平移到正值小坐标，校验其 numpy 参照能量不变，减少浮点周期包裹损失；不改变构型。
- 后续如需混合精度专用验收政策，必须先提供数值误差来源的独立定量证据并明确政策变化；本次严格 Gate 的失败应如实保留。没有安装新引擎或改变已有环境包。
